# Documentation Archive

This folder is for historical Yuplan documentation that remains useful as evidence but must no longer look like current product/architecture authority.

## Archive is not deletion
Archived files may still explain:
- legacy behavior;
- migration/parity decisions;
- old acceptance evidence;
- superseded proposals;
- dated handoffs;
- old release/staging procedures.

## Before moving a file
1. Check whether current docs link to it.
2. Promote any still-current rule to Ground Truth or an active reference.
3. Update links.
4. Move the historical file without rewriting its content merely to make it look current.
5. If a locked decision is superseded, record that in Ground Truth DECISION_LOG.
