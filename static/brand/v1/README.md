# Yuplan Brand Assets 1.0

Canonical asset root: `static/brand/v1/`

This folder contains the official Brand Base 1.0 assets for the Yuplan logo and mascot.

## Official logo

- SVG master: `logo/yuplan-mark-primary.svg`
- PNG: `logo/yuplan-mark-primary-2048.png`
- PNG: `logo/yuplan-mark-primary-1024.png`
- PNG: `logo/yuplan-mark-primary-512.png`
- PNG: `logo/yuplan-mark-primary-256.png`

The SVG is the canonical vector asset. The PNGs are transparent raster exports.

## Mascot

- PNG: `mascot/yuplan-mascot-primary-2048.png`
- PNG: `mascot/yuplan-mascot-primary-1024.png`
- PNG: `mascot/yuplan-mascot-primary-512.png`

The mascot SVG in the incoming package is intentionally not installed as a canonical asset. The PNGs are the canonical mascot assets until a true vector version exists.

## Colors

The logo identity colors are:

- Cyan: `#3BA9E5`
- Teal: `#12B7A5`
- Deep teal: `#0AA090`
- Yellow accent: `#FFD166`
- White: `#FFFFFF`

The product/UI colors are documented in `docs/brand/YUPLAN_BRAND_BASE_1_0.md`.

Manrope är Yuplans primära typfamilj.

## Important

No alternative or mono logo proposals are canonical assets here. Files marked `Primary` are the official main assets.
